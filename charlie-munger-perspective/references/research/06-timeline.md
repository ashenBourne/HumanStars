## 早年生活与教育 (1924-1948)

| 年份 | 事件 | 意义/影响 |
|------|------|-----------|
| 1924年1月1日 | 出生于内布拉斯加州奥马哈，父亲Alfred Munger(律师)，母亲Edna | 出生在经济大萧条前夕，早期经历塑造对风险和人性理解 |
| 1930年代 | 童年经历大萧条，家庭经济困难；父母离异随母亲生活 | 亲历经济极端波动，形成坚韧性格 |
| 1942年 | 进入密歇根大学学数学 | 培养量化思维基础，接触推理 |
| 1943年(19岁) | 加入美国陆军航空队，二战服役 | 学习工程学、气象学，获少尉军衔；军事纪律和领导力 |
| 1945年 | 二战结束退役；获准进入哈佛法学院(通过二战培训项目) | 凭借优异成绩进入顶尖法学院 |
| 1946年 | 从哈佛法学院毕业，获J.D.学位 | 成为罕见的在一年内完成学业的毕业生 |
| 1948年 | 通过加州律师考试，开始在洛杉矶执业 | 开启法律职业生涯 |

## 法律与早期投资 (1948-1962)

| 年份 | 事件 | 意义/影响 |
|------|------|-----------|
| 1948-1950s | 在小律所工作，后组建Wheeler, Munger律师事务所 | 接触房地产和商业交易 |
| 1948年 | 与Nancy Huggins结婚，后育有三子一女(4个孩子) | 建立家庭，子女教育成为重心 |
| 1950年代初 | 开始参与房地产开发，购买公寓楼 | 首次实践投资，积累原始资本 |
| 1959年 | 与Jack reaches合作进行石油投资 | 扩展到自然资源领域，验证投资才华 |
| 1960年 | 首次遇到Warren Buffett | **关键人生转折点**，开启世纪投资合作 |

## 投资合伙与早期挑战 (1962-1978)

| 年份 | 事件 | 意义/影响 |
|------|------|-----------|
| 1962年 | 成立Munger Investment Company | 从律师向全职投资人转变 |
| 1962-1976 | 管理多个合伙企业，年均回报~19%(扣费前) | 显著跑赢市场，建立声誉 |
| 1964年 | 开始持有Blue Chip Stamps股份 | 后来成为与Buffett合作的重要平台 |
| 1972-1973 | 间接投资See's Candies(通过Blue Chip) | 真正理解"护城河"企业价值，成为经典 |
| 1973-1974 | 过度杠杆导致-50%回撤，1978被迫清算 | **终身教训**：形成"Never use leverage"铁律 |
| 1974年 | 个人财富约$125M(相当于2024年$750M) | 投资已取得巨大成功 |
| 1978年 | Munger合伙与Berkshire Hathaway完全合并 | **正式成为Berkshire副董事长**，45年共同治理开始 |

## Berkshire副董事长时代 (1978-2023)

| 年份 | 事件 | 意义/影响 |
|------|------|-----------|
| 1978年起 | 担任副董事长，与Buffett形成"双引擎"治理模式 | 重大决策共同讨论，互补：Buffett定量，Munger定性+心理学 |
| 1970年代末 | 推动收购Wesco Financial股权(1980年完成) | 将Wesco并入帝国，作为子资本平台 |
| 1983年 | 推动华盛顿邮报公司投资 | 展示"优质企业+护城河"威力 |
| 1986年 | 开始强调"多元思维模型"系统化 | **思想从投资技巧提升到跨学科智慧框架** |
| 1986-1990 | 受心理学影响(Cialdini等)，系统收集人类误判心理学 | 开始构建25种心理倾向清单 |
| 1988-1989 | 参与可口可乐重大投资决策 | 经典"护城河"投资，持有数十年 |
| 1993年 | 推动收购Dexter Shoe(后期完全减值) | **高额学费**，此后更强调"护城河厚度" |
| 1994年6月 | USC法学院毕业典礼演讲，首次完整公开25种心理倾向 | **公开思想核心**，影响后世无数投资者 |
| 1995年5月 | 哈佛法学院毕业典礼演讲，主题"To-the-Bottom-of-the-Page" | 强调专业精神、逆向思维、担当 |
| 1995年 | 正式成为Daily Journal董事长 | 获得稳定现金流平台和年度股东大会讲坛 |
| 1996年起 | 每年在Daily Journal洛杉矶股东会发表2小时讲话 | 近30年传统，价值投资"圣地" |
| 1998年 | 首次心脏病发作，接受支架手术 | 健康首次亮红灯，仍高强度工作 |
| 2000年代初 | 开始系统批评现代会计制度和华尔街短视 | 利用副董事长平台疾呼商业伦理 |
| 2005年 | Poor Charlie's Almanack出版 | **思想体系正式成书**，成为投资圈"圣经" |
| 2009-2010 | 接受白内障手术 | 晚年健康问题凸显 |
| 2010年 | 个人财富约$15亿 | 财富稳健增长 |
| 2015年 | 91岁接受采访谈"生活智慧" | 思想影响力扩展到投资外 |
| 2016年 | 92岁的巴菲特宣布Munger为Berkshire董事长继承人 | **官方确认历史地位** |
| 2018年 | 94岁仍主持Daily Journal年会，思维敏捷 | 证明extraordinary longevity和认知保持 |
| 2020-2021 | 疫情期间出席股东会，批评美联储"印钞"政策 | 保持活跃到95+ |
| 2021年 | 卸任Daily Journal董事长，保留董事 | 逐步交棒 |
| 2022年 | 98岁参与$116亿Alleghany收购 | **最后一个重大投资决策** |
| 2023年5月 | 最后一个Berkshire股东大会共同主持(99岁) | 99年人生的里程碑，告别Berkshire舞台 |

## 思想发展里程碑

| 年份 | 事件 | 意义/影响 |
|------|------|-----------|
| 1970年代初 | 受格雷厄姆影响但不满"烟蒂"法，发展"以合理价格买入优质企业" | 价值投资分水岭 |
| 1978年后 | 与Buffett强调"quality over price" | 推动Berkshire收购See's、Washington Post等优质企业 |
| 1980年代中期 | 深入研究心理学(Cialdini等)，自学人类误判心理学 | 跨学科思维开端 |
| 1986年 | 首次提出"多元思维模型"，引用物理、生物、心理、经济 | **系统化智慧框架**，超越纯投资 |
| 1994年 | USC演讲完整列出25种心理倾向 | **公开思想核心**，成为商学院标准内容 |
| 1995-2000 | 阐述"lollapalooza effect"(多因素共振) | 强调多学科交叉非线性威力 |
| 2005年 | Poor Charlie's Almanack出版 | **体系成书**，确立"理性、跨学科、逆向"方法论 |
| 2010年代 | 开始强调"luck"与"skill"平衡，承认财富积累含重大运气 | 谦逊，区分可控与不可控 |
| 2020年代 | 批评"woke capitalism"、ESG过度，强调传统商业伦理 | 思想延伸到社会文化评论 |

## 关键转折点总结

1. **1924-1948**：早年经历(奥马哈、大萧条、二战)塑造抗逆力、纪律、自学能力
2. **1960**：遇见Buffett——**最关键相遇**
3. **1978**：正式合并进入Berkshire，担任副董事长
4. **1986**：提出多元思维模型框架，成为思想家
5. **1994**：USC演讲公开25种心理倾向——系统化思想传播
6. **2005**：Poor Charlie's Almanack出版——思想遗产成书
7. **2024.1.1**：100岁寿辰——世纪人生里程碑
8. **2024.5**：Daily Journal最后会议——公开讲话生涯终结
